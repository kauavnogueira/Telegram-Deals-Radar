# Telegram Deals Radar

Real-time Telegram deal monitor and discount aggregator. Connects directly to Telegram channels via MTProto, extracts promotional pricing, discount percentages, coupons, and product media, and serves an interactive dashboard with filtering, search, and dynamic channel management.

Powered by Next.js, React 19, TypeScript, Tailwind CSS, and Node.js native SQLite (`node:sqlite`).

---

## Architecture

- **MTProto Collector Worker**: Uses Teleproto to maintain a persistent connection, listening to `NewMessage` events and reading channel history.
- **Parser Engine**: Extracts current price, original price, discount percentage, coupon codes, and store affiliate links from unformatted Portuguese channel messages. Filters promotional slogans and channel banners.
- **Storage Layer**: SQLite via Node.js native `node:sqlite` in WAL mode (`PRAGMA journal_mode = WAL`) with busy timeout handling for concurrent access between the Next.js process and the collector worker.
- **Web Application**: Next.js App Router providing REST API endpoints, real-time UI updates, infinite scrolling, price range filtering, and channel management.

---

## Prerequisites

- **Node.js**: `v22.12.0` or higher (required for native `node:sqlite`).
- **Telegram Account**: `API ID` and `API HASH` obtained from [my.telegram.org](https://my.telegram.org) under *API development tools*.

## Quickstart

### 1. Clone the repository

```bash
git clone https://github.com/seu-usuario/coletor-telegram.git
cd coletor-telegram
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run interactive configuration

```bash
npm run setup
```

The CLI prompt will guide you through:
1. Entering your `TELEGRAM_API_ID` and `TELEGRAM_API_HASH`.
2. Specifying default channels to monitor (e.g. `@promobitoficial, @ofertaztelegram`).
3. Authenticating with your phone number and Telegram verification code (plus 2FA password if enabled).

The setup wizard writes your credentials and encrypted session string to `.env.local` and initializes the SQLite database.

### 4. Start the application

```bash
npm run dev
```

This concurrently starts:
- The Next.js web application on `http://localhost:3000`.
- The background MTProto collector worker syncing recent messages and streaming new offers.

## Key Features

- **Automated Data Extraction**:
  - Promotional and list price detection ("De/Por", "À vista", "Pix").
  - Discount percentage calculation (`% OFF`).
  - Coupon code extraction with validation against stop words.
  - Store identification (Amazon, Mercado Livre, Shopee, AliExpress, KaBuM!, Magalu, Casas Bahia, etc.).
- **Media Ingestion**: Product images downloaded directly from Telegram media payloads and served locally.
- **Dynamic Channel Management**: Add, remove, pause, or force-sync channels from the web interface without restarting background workers.
- **Search & Filtering**: Full-text search with accent normalization, dual-slider price range filter, store and channel facets, and sorting by price, discount, or date.
- **Dual Views**: Dedicated tabs for products and store coupons.
- **Zero Native Build Dependencies**: Runs on standard Node.js without requiring `node-gyp` or external C++ build chains.

## Configuration

Environment variables are loaded from `.env.local`:

| Variable | Description |
| --- | --- |
| `TELEGRAM_API_ID` | Telegram API identifier from my.telegram.org |
| `TELEGRAM_API_HASH` | Telegram API 32-character hexadecimal hash |
| `TELEGRAM_STRING_SESSION` | Encrypted session token generated by `npm run setup` or `npm run login` |
| `TELEGRAM_CHANNELS` | Comma-separated fallback list of channel handles to monitor |

## API Endpoints

### Products

- `GET /api/products` — Query products with pagination, search, store, channels, price range, and sorting.
- `POST /api/products` — Parse and save raw Telegram message text manually.
- `DELETE /api/products?id=<id>` — Remove a product by ID (or `?all=true` to truncate).

### Coupons

- `GET /api/coupons` — Query extracted coupon vouchers with search, store, and channel filters.
- `DELETE /api/coupons?id=<id>` — Remove a coupon by ID.

### Channels

- `GET /api/channels` — List all monitored channels and their item counts (`?activeOnly=true` supported).
- `POST /api/channels` — Add a channel username (body: `{ channel: string, title?: string }`).
- `PATCH /api/channels` — Toggle channel active status (body: `{ channel: string, isActive: boolean }`).
- `DELETE /api/channels` — Remove a channel from monitoring.

### Metrics & Sync

- `GET /api/stats` — Aggregate metrics: total products, coupons, average price, average discount, store counts, and channel counts.
- `POST /api/collector/fetch-more` — On-demand historical sync via MTProto (body: `{ limit?: number, channel?: string }`).

## Security & Privacy

- **Local Storage**: All credentials, session keys, databases (`data/products.sqlite`), and media files remain on your local machine.
- **Git Ignore**: `.env.local`, SQLite files, and downloaded product images are ignored in `.gitignore` to prevent credential exposure.
- **Session Security**: Keep `TELEGRAM_STRING_SESSION` secure; it provides direct access to your Telegram account.
